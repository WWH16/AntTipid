# Product

## Register

product

## Users
Individuals and budget-conscious users looking to track income, expenses, monthly budgets, and financial health in the Philippines (₱ PHP).

## Product Purpose
AntTipid is a sleek, modern personal finance tracking web application that provides real-time balance overviews, monthly budget progress bars, category breakdowns, and transaction histories.

## Brand Personality
Calculated prosperity, modern financial clarity, precise and trustworthy.

## Anti-references
Cluttered traditional banking web apps, washed-out low-contrast SaaS templates, cramped mobile layouts.

## Design Principles
1. Responsive Unity: Identical visual language and design system between mobile and desktop displays.
2. High-Contrast Financial Clarity: Readability first for amounts, dates, and categories.
3. Content-First Spacing Rhythm: Touch-friendly 44px targets on mobile, 4/8/16/24/32px spacing system.

## Accessibility & Inclusion
WCAG AA contrast compliance, minimum 44px touch targets for mobile interactive elements, clear icon-to-text pairing.
